### US-002 — Parent-side `guard_head_advance` defense-in-depth

Per spike-3 sketch in synthesis doc:

```bash
# Before dispatch (~line 1594, inside COORDINATOR_MODE==true block):
HEAD_BEFORE_COORD=$(git rev-parse HEAD)

# After dispatch + runner_parse_output + timeout override (~line 1672):
if [[ "$COORDINATOR_MODE" == "true" ]]; then
  source "$SCRIPT_DIR/lib/coordinator-guard.sh"
  if ! guard_head_advance "$HEAD_BEFORE_COORD"; then
    printf "ERROR: Parent-side HEAD guard fired. HEAD_BEFORE=%s, HEAD_AFTER=%s\n" \
      "$HEAD_BEFORE_COORD" "$(git rev-parse HEAD)" >&2
    SIGNAL_RESULT="WAVE_FAILED"
  fi
fi
```

**Defense-in-depth: keep BOTH layers.** LLM-side instruction at `agents/coordinator.md` step 2 stays (per-story attribution). Parent-side adds instruction-following independence.

**ACs:**
- [ ] HEAD capture at `quantum-loop.sh:~1594` (before `eval`).
- [ ] Guard invocation at `quantum-loop.sh:~1672` (after timeout override, before STORY_* redirect).
- [ ] On guard failure: print ERROR (pattern: `Parent-side HEAD guard fired`) + force `SIGNAL_RESULT="WAVE_FAILED"`.
- [ ] New Test 8 in `tests/test_coordinator_e2e.sh` with `head_reset` stub mode (does `git reset --hard HEAD~1` then echoes WAVE_PASSED). Asserts ERROR + stories failed.

### US-003 — ADR-001: Outer-loop architecture decision record

Author `references/adr-001-outer-loop-architecture.md` (NEW):
- Status: ACCEPTED (2026-05-01)
- Context: v0.9.x track shipped per-wave coordinator dispatch; outer iteration loop runs N waves bounded by `--max-iterations`. Operator workflow uses Claude Code `/loop` cron pattern for unattended autonomous cycles.
- Decision: cron-triggered `/loop` is the canonical outer-loop architecture; no persistent-daemon implementation will be built.
- Consequences: zero PID/signal complexity; cross-platform robust; trivial stop/restart semantics.
- Triggers for revisit: Claude Code `/loop` deprecation; demonstrated operational failure of cron pattern.

Update `idea-stage/IDEA_REPORT_v31.md` to reference the new ADR + remove "daemon-style runner" from forward-looking sections.

**ACs:**

- [ ] `idea-stage/IDEA_REPORT_v31.md` updated with ADR reference.

## Risks + mitigations

1. **Decomposition introduces test regression** — mitigation: TDD-style validation; run all 6 v0.9.x test suites after each extraction step.
2. **Shell-global coupling breaks under decomposition** — mitigation: spike-1 documented the contract; sourcing preserves scope.
3. **Parent-side guard duplicates LLM-side check** — mitigation: keep both layers (per spike-3 recommendation).
4. **N45 external helper race during refactor** — mitigation: commit frequently; `git reset --hard origin/master` recovery if drift detected.
