## Overview

v0.7.4 dogfood surfaced two LOW process gaps:
- **N29:** advisory-hook CSV updates may not get staged/committed before squash-merge (v0.7.2/v0.7.3 missed it).
- **N31:** `/ql-spec` skill PRD generation can hallucinate file paths that don't exist (v0.7.4 US-004 cited `tests/test_worktree_isolation.sh` and `lib/type-auditor.sh` — neither exists).

Both are small fixes that prevent future repeats of identified bugs.

## Per-story design notes

### US-001 — N29: CSV-commit audit warning

**Problem:** v0.7.2/v0.7.3 advisory-hook CSV rows were never staged/committed. `quantum-loop.sh --audit` doesn't currently check for this.

**Decision:** Add a new audit check `csv-uncommitted` to `quantum-loop.sh --audit`:
- `git status --porcelain metrics/pre-impl-review-findings.csv` returns non-empty → WARN (not FAIL — advisory level).
- Add 1 new test in `tests/test_audit.sh` (synthesize uncommitted CSV → run audit → grep WARN line).

### US-002 — N31: spec grep-verify instruction

**Problem:** `/ql-spec` skill PRD generation can cite file paths that don't exist (LLM hallucination).

**Decision:** Edit `skills/ql-spec/SKILL.md` Step 1 (Gather Context) to add: "When citing a file path in any AC, run a grep/ls verification that the path exists OR add explicit annotation `[NEW]` if the path is being created by this PRD."

This is a doc-only edit to the skill prompt. No runtime change.

### US-003 — retrospective

Standard retrospective + IDEA_REPORT_v16 + 3-manifest version bump 0.7.4 → 0.7.5.
