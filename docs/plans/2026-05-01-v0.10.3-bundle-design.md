## Decisions

### test_v081_wiring.sh: DELETE rather than restore

The 4 failing assertions check v0.8.1-era placeholder behaviors that v0.9.0 properly replaced:
- `WARN coordinator not wired` — was v0.8.1 stub; v0.9.0 implemented real coordinator dispatch.
- `ql_wrap_subagent_dispatch zero callers` — gated OFF under coordinator mode per v0.9.0/v0.9.3.
- `dead -z SIGNAL_RESULT form` — v0.8.1 US-006 fixed; post-decomposition the guard moved to lib/iteration-loop.sh.
- `COORDINATOR_MODE=true silently falls through` — v0.9.0 N42 wired real dispatch.

**Rewriting** would mean inventing new assertions for v0.9.0+ wires. But those are already covered by:
- `tests/test_coordinator_e2e.sh` (21 cases; coordinator dispatch end-to-end)
- `tests/test_dag_query.sh` (44 cases; DAG + filter_file_conflicts + next_wave)
- `tests/test_next_wave.sh` (18 cases; next_wave unit)
- `tests/test_coordinator_dispatch.sh` (coordinator dispatch unit)
- `tests/test_coordinator_guard.sh` (HEAD-snapshot guard)

**Decision: DELETE.** v0.8.1 smoke is fully subsumed by current coverage. Keeping it as 4/5-failing-but-not-broken adds noise without value.

### Deferred dogfood: STILL DEFER

No operator feature queued for dogfood. v0.10.0 PRD established the clean-deferral path: status=deferred, retro notes deferral, cycle ships. Same condition holds. v0.10.3 will note 4th cycle of deferral (v0.10.0 → v0.10.1 → v0.10.2 → v0.10.3) and document the dogfood pattern as "blocked-on-operator-feature-queue."
