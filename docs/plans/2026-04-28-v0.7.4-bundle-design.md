## Architecture / cross-cutting concerns

**Dogfood-as-test:** The pipeline run *is* the test for #2/#4 — each successful skill invocation validates the corresponding feature. If a skill fails, that's the dogfood discovery.

**Fallback discipline:** If any skill drifts mid-cycle, fall back to manual takeover (proven 6-cycle reliability). Drift discovery itself is data for IDEA_REPORT_v15.

**Per-story dual-review:** After each story passes, invoke BOTH `/soliton:pr-review` (current pattern) AND `copilot:copilot-rescue` (operator-requested). Compare outputs in retrospective.

**Multi-runner-manifest is foundation only:** No actual codex/gemini runner code lands in v0.7.4. The lib + schema + tests are purely structural. This is deliberate to prevent scope creep into minor-tier territory.

## Risk + mitigations

| Risk | Likelihood | Mitigation |
|---|:-:|---|
| Skill drift in `/ql-execute` worktree mode (6-cycle baseline = 100% drift) | HIGH | Manual takeover per established SOP. Document drift in retrospective. |
| Wave 0 file conflicts at merge time despite `fileConflicts: []` | LOW | Each story scoped to disjoint files; dag-validator pre-flight catches. |
| `claude` CLI unavailable during US-001 smoke test | MEDIUM | Skip-pass design (defaults Q1=B). |
| Multi-runner-manifest YAML parser missing on Git Bash | LOW | Use `python3 -c 'import yaml; ...'` or `yq` if available; fall back to handcrafted shell parser for the trivial schema. |
| Plan-review MEDIUM still doesn't trigger | MEDIUM | Track as N26 follow-up; not blocking. |
| copilot:copilot-rescue produces noise/contradicts soliton | MEDIUM | First-time observation — capture both, let operator adjudicate. |

## Testing Strategy

- **Unit:** per-story tests added (US-001 +1, US-002 new file, US-003 +1, US-004 +1, US-005 new file 6 tests).
- **Integration:** dogfood pipeline IS the integration test for #2/#4.
- **Regression:** `bash tests/run_all.sh --parallel 4` after merge — must remain 100% green.
- **G30 self-validation:** US-007 captures expected score (likely LOW given file count + no sensitive paths in v0.7.4 itself).

## Edge Cases & Error Handling

- `claude` CLI absent → US-001 skip-pass.
- YAML parse error in manifest → US-005 `parse_manifest` returns 1 + emits stderr error.
- Worktree creation failure on old git → US-004 skip-pass.
- Routing config missing required role → US-002 `route_for_role` falls back to default with stderr WARN.
