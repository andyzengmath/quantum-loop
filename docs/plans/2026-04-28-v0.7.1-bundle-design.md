**Decision:** Add a fixture-driven test in `tests/test_deep_review_dispatch.sh`: synthesize a patch with `sensitive_hits=2` (e.g., 2 paths matching `*.env` + `auth/`) → `should_dispatch_deep_review` returns 0 (dispatch); the test ALSO invokes `dispatch_set MEDIUM` and asserts the returned reviewer list has the expected 4 reviewers (oh-my-claudecode:code-reviewer, soliton:synthesizer, oh-my-claudecode:security-reviewer, oh-my-claudecode:test-engineer). Pure unit-test of the dispatch chain — no actual reviewer-agent spawning needed.

**Files:** `tests/test_deep_review_dispatch.sh` (extend with Test 8).

**Verification:** existing 15 assertions remain green; +3 new assertions (dispatch returns 0, dispatch_set MEDIUM returns 4 reviewers, reviewer list contains expected agent names).

### US-002 — N20: N14 SKILL wrapping runtime extraction

**Problem:** v0.7.0 N14 ships SKILL.md prose for orchestrator-liveness wrapping. Presence-only AC; no runtime test exists.

**Decision:** Extract the wrapping logic into a new function `wrap_orchestrator_dispatch` in `lib/orchestrator-liveness.sh`:

```bash
# wrap_orchestrator_dispatch [timeout_sec] [interval_sec]
# Wraps a parent-agent's orchestrator dispatch with liveness polling.
# Honors QL_LIVENESS_ENABLE env var (default true).
# On STALE: emits handoff message to stdout + returns 1.
wrap_orchestrator_dispatch() {
  if [[ "${QL_LIVENESS_ENABLE:-true}" == "false" ]]; then
    return 0  # opted out
  fi
  if poll_orchestrator_commits "${1:-600}" "${2:-60}"; then
    return 0
  fi
  cat <<'HANDOFF'
[QL-EXECUTE] orchestrator-stale signal. Recovery procedure:
  1. Read references/orchestrator-takeover.md (manual-takeover SOP).
  2. Verify drift via git log <BASE>..HEAD --oneline + jq status query.
  3. Continue the in-progress story manually; commit normally.
HANDOFF
  return 1
}
```

The SKILL.md cites the function instead of inlining the logic. Test: invoke `wrap_orchestrator_dispatch 2 1` with `QL_LIVENESS_ENABLE=false` (expect rc=0 silent skip); invoke with default (expect STALE handoff + rc=1).

**Files:** `lib/orchestrator-liveness.sh` (extend), `skills/ql-execute/SKILL.md` (replace inline logic with function reference), `tests/test_orchestrator_liveness.sh` (Test 6 + Test 7 covering both branches).
