## Patterns Observed

**What worked well:**
- The seam between Run 2 and Run 3 was clean: T-001 + T-002 had on-disk artifacts (`lib/finding-persist.sh` + `tests/test_finding_persist.sh`) but quantum.json task statuses were still `pending`. The Run 3 orchestrator marked them passed without re-implementing, then proceeded with T-003 onward — RED→GREEN transition worked exactly as designed (8/10 → 37/37 after T-003-T-006).
- DAG `dependsOn` correctly serialized US-002 after US-003 even though `fileConflicts` flagged `skills/ql-plan/SKILL.md` as severity:low. Different sections (Step 8 = US-003 regex source; Step 9 = US-002 plan-review wrapper) — no merge conflict materialized.
- TDD discipline held across all 7 stories: every `testFirst:true` task wrote a RED test before implementation. Most visible in US-005 where test 23's expectation changed (6/6 → 7/7) BEFORE the helper was added — RED on first-run, GREEN after T-002.
- The G15 CHANGELOG-ownership convention (US-006) self-validated: only US-007 touches CHANGELOG.md (count=1), no warning emitted, convention holds.

**Recurring caveat (3rd time across releases):**
- **Self-modifying-orchestrator caveat.** v0.7.0's instrumentation (G13 persistence + G17 audit) targets the planner/skills, but the orchestrator running THIS bundle was the v0.6.3 master HEAD orchestrator. So the new wires apply to NEXT runs only. The `metrics/pre-impl-review-findings.csv` is empty at end-of-run, and the audit correctly reports `pre-impl-review-coverage: 0/3 stages WARN missing-csv`. This is the 3rd retrospective in a row to surface this caveat (also v0.6.0 / v0.6.3) — IDEA_REPORT_v5 G20 proposes a one-paragraph README note for v0.7.1.

**Suggested improvements for v0.7.x:**
- (G18) Audit drill copy: add "(expected on first run after v0.7.0 install)" to the WARN missing-csv message — closes the "is the audit broken?" reaction.
- (G19) The 3 SKILL wrappers in US-002 are textually identical and verified-by-grep. Works for now; if a 4th pre-impl-review stage is ever added, refactor to `lib/spec-review-wrapper.sh`.
- (G20) Self-modifying caveat should be a permanent README section, not just a per-release retrospective bullet.
- (G21) `metrics/` rotation policy needed before the CSV grows unbounded. Defer to v0.8.x — premature at <100 rows.
- (G22) Severity rubric calibration: blocked on ≥1 release of CSV data accumulating. v0.7.2+ retrospective.
