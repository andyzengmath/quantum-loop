## 5. Risks & Mitigations

| Risk | Likelihood | Mitigation |
|------|-----------|-----------|
| CPC variant has latent regression the plain version didn't | Low | Phase 2 promotes one file at a time + runs test suite after each; rollback pattern defined. |
| `ql/multi-runner` merge produces > 3 unrelated conflicts | High | Design doc §P0.D defines abort + tag + escalate recovery (already critic-reviewed). |
| Destructive branch deletion loses unflushed work | Low | `archive/pre-delete-<branch>-<date>` tag before every branch deletion; `git reflog` retained. |
| Working-tree untracked files clobbered | Medium | Never run `git clean -fd`; never `git reset --hard` master; keep work on integration branch. |
| P1 skills not backward-compatible with in-flight `quantum.json` schemas | Medium | `userIntent` + `codebasePatterns` fields optional; `/ql-verify` fallback path for missing fields logs warning, does not block. |
| Post-mortem generator fix masks a deeper orchestrator bug | Medium | Require failing-story fixture test in Phase 6; verify lesson actually reaches `codebasePatterns`. |
| Deslop deletes load-bearing code | Medium | Mandatory post-deletion test re-run + rollback; scope fence to story `filePaths`. |
| Dogfood reveals pipeline still broken on self-use | Medium | Dogfood scoped to one trivial story; if it fails, capture evidence as G22 and defer P1 close-out to next cycle. |
